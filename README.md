# My configuration files

My config files for both my desktop PC and laptop.

## Usage

To load the config on your device you can use:
```./load_config.sh (desktop | laptop)```
It will copy the config files from the repo to their respective places in the filesystem.

---

To update the config with the files from your device you can use:
```./update_from_disk.sh (desktop | laptop)```
It will update the files in the repo with the ones from your pc.
